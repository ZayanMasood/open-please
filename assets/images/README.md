# Optional photo files

The website already looks complete without photos. To add your own images, place them in this folder using these exact names:

- `stem-workshop.jpg` — used behind the Open Lab artwork
- `creative-play.jpg` — used behind the Open Studio artwork
- `community-circle.jpg` — used behind the Open Circle artwork

Recommended image settings:

- Landscape orientation
- At least 1600 x 1000 pixels
- JPG or WebP-quality source converted to JPG
- Keep important faces and details near the center
- Compress each image to roughly 300 KB or less when possible

The gradients remain on top of the photos, so text and animated graphics stay readable. Use only images you have permission to publish. For photos of children, obtain appropriate written parent or guardian consent through the host organization before posting them publicly.
